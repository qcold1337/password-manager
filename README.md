## 🚀 Быстрый старт (Quick Start)

### Требования
* **Python** версии 3.10 или новее.
* Модуль `cryptography` для работы с AES-шифрованием.

---

### 📱 Установка и запуск в Termux (Android)

Для работы в Termux рекомендуется устанавливать криптографические зависимости через системный пакетный менеджер `pkg`, чтобы избежать проблем с компиляцией бинарных модулей Rust (`_rust.abi3.so`).

1. **Обновите пакеты и установите Python с библиотекой шифрования:**
   ```bash
   pkg update && pkg upgrade -y
   pkg install python python-cryptography -y
